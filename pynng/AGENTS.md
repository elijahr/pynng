## Socket Class Hierarchy

All protocol sockets inherit from `Socket` (nng.py:160). Each subclass sets `_opener` to its nng open function.

```
Socket (base - cannot be instantiated directly)
  +-- Bus0          (nng_bus0_open)
  +-- Pair0         (nng_pair0_open)
  +-- Pair1         (nng_pair1_open or nng_pair1_open_poly)
  +-- Push0         (nng_push0_open)
  +-- Pull0         (nng_pull0_open)
  +-- Pub0          (nng_pub0_open)
  +-- Sub0          (nng_sub0_open) - adds subscribe()/unsubscribe(), topics kwarg
  +-- Req0          (nng_req0_open) - adds resend_time option
  +-- Rep0          (nng_rep0_open)
  +-- Surveyor0     (nng_surveyor0_open) - adds survey_time option
  +-- Respondent0   (nng_respondent0_open)
```

### Adding a New Protocol

1. Create a subclass of `Socket` in `nng.py`
2. Set `_opener = lib.nng_protocolname_open`
3. Add any protocol-specific options as class-level descriptors
4. Accept protocol-specific kwargs in `__init__`, pass through to `super().__init__(**kwargs)`
5. Export from `__init__.py`
6. Add the protocol header to `build_pynng.py`'s header list (line ~133)
7. Write tests in `test/test_protocols.py`

## Option Descriptor System

Options are declared as class attributes using descriptor subclasses of `_NNGOption` (nng.py:73):

```python
# In a Socket subclass:
recv_timeout = MsOption("recv-timeout")
name = StringOption("socket-name")
raw = BooleanOption("raw")  # read-only if no setter
```

Available descriptor types:

| Descriptor | C Type | Read | Write |
|------------|--------|------|-------|
| IntOption | int | yes | yes |
| MsOption | nng_duration (ms) | yes | yes |
| SizeOption | size_t | yes | yes |
| StringOption | char* | yes | yes |
| BooleanOption | bool | yes | yes |
| SockAddrOption | nng_sockaddr | yes | no |
| PointerOption | void* | no | yes |
| NotImplementedOption | N/A | raises | raises |

### Adding a New Option

1. Choose the correct descriptor type for the C option's type
2. Add as a class attribute: `my_option = MsOption("nng-option-name")`
3. The option name string must match the nng C option name exactly
4. If the option should be settable at construction time, add it to the `__init__` kwargs handling

## Error Handling

**Convention**: Call `check_err(ret)` immediately after every C function call.

```python
ret = lib.nng_some_function(args)
check_err(ret)  # raises appropriate NNGException subclass if ret != 0
```

`check_err` (exceptions.py:187) looks up the error code in `EXCEPTION_MAP` and raises the matching exception with the nng error string.

Never use bare `if ret != 0` checks. Always use `check_err`.

## Memory Management Rules

These patterns prevent segfaults and leaks. Violating them causes crashes.

### 1. Socket close guard
```python
def close(self):
    if hasattr(self, "_socket"):  # guard: __init__ may have failed
        lib.nng_close(self.socket)
```

### 2. Message ownership transfer
When a Message is sent, nng takes ownership of the C memory. The Message object tracks this:
```python
self._mem_freed = False
self._mem_freed_lock = threading.Lock()
```
- `send_msg()` sets `_mem_freed = True` BEFORE returning
- `__del__` checks `_mem_freed` before calling `nng_msg_free`
- `_ensure_can_send()` raises `MessageStateError` if already sent
- The lock handles concurrent send + GC on different threads

### 3. String option memory
After `nng_*_get_string()`, the returned char* must be freed with `nng_strfree()`. See options.py:132-141.

### 4. AIO double-free prevention
Set `self.aio = None` after `nng_aio_free()`. Both `__exit__` and `__del__` call `_free()`, so the None check prevents double-free.

### 5. Pipe struct copy
In pipe callbacks, copy the pipe value to avoid memory corruption:
```python
self._pipe = ffi.new("nng_pipe *")
self._pipe[0] = lib_pipe  # copy struct value
```

### 6. AIO callback map
`_aio_map` (module-level dict in _aio.py) keeps Python callback objects alive while C async operations are pending. Without this, GC could collect the callback before nng invokes it.

## Async Architecture

### Flow
1. `Socket.arecv()` creates an `AIOHelper` context manager
2. `AIOHelper.__init__` allocates `nng_aio` with `_async_complete` as the C callback
3. `sniffio.current_async_library()` selects the event loop bridge
4. The bridge returns `(awaitable, rescheduler)` where rescheduler is stored in `_aio_map`
5. nng performs the operation on its internal thread
6. On completion, `_async_complete` (C callback) looks up and calls the rescheduler
7. The rescheduler wakes the awaitable on the correct event loop

### Cancellation
- asyncio: `asyncio.shield(fut)` + `nng_aio_cancel` on `CancelledError`, loop until nng confirms
- trio: `abort_fn` calls `nng_aio_cancel`, returns `Abort.FAILED` to keep waiting

### Thread Safety
- `_aio_map` is accessed from both nng C threads and Python event loops
- `Socket._pipe_notify_lock` protects `_pipes` dict during pipe callbacks
- `Message._mem_freed_lock` protects the freed flag

## Code Conventions

- `to_char(charlike)` (nng.py:60): Convert str/bytes to `char*` for CFFI. Used everywhere.
- `_ensure_can_send(thing)` (nng.py:45): Raises ValueError if user passes str instead of bytes.
- `import pynng` in nng.py and options.py to avoid circular imports (not `from pynng import X`).
- All C function calls go through `check_err(ret)`. No exceptions.
- Context managers for all resources (Socket, Context, AIOHelper, TLSConfig).
